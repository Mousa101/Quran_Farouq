# حافظ - تطبيق تتبع حفظ القرآن
## Product Requirements Document

### المشكلة الأصلية
تطبيق لإدارة ومتابعة طلاب تحفيظ القرآن الكريم في المراكز القرآنية. يشمل نظام للطلاب، المعلمين (الشيوخ)، والمدراء.

### الميزات الأساسية

#### 1. إدارة المستخدمين
- تسجيل الطلاب والشيوخ والمدراء
- نظام أكواد التسجيل
- تفعيل الحسابات

#### 2. نظام التسميع
- تسجيل التسميع اليومي (حفظ جديد/مراجعة)
- تتبع الصفحات والأجزاء
- حساب نسبة التسميع

#### 3. ورقة المتابعة الإيمانية (100 نقطة/أسبوع)
- تتبع الصلوات والأذكار
- الوتر والسنن وقيام الليل
- الصيام والجلوس مع القرآن

#### 4. نظام الحضور والغياب
- تسجيل الحضور اليومي
- حساب نسبة الحضور

#### 5. نظام النقاط والشارات
- نقاط الحضور (10 نقاط/يوم)
- نقاط التسميع (20 نقطة/تسميع)
- نقاط ورقة المتابعة (100 نقطة/أسبوع)
- شارات أسبوعية (العابد، الملتزم، الحافظ، المتفاعل)

#### 6. نظام إدارة الفصول الدراسية (جديد)
- إغلاق الفصل الحالي وأرشفة البيانات
- بدء فصل جديد
- الحفاظ على النقاط التراكمية الإجمالية

## ما تم تنفيذه

### الجلسة الحالية (18 فبراير 2026)

#### P0 - تم الإنجاز:
1. **نظام إدارة الفصول الدراسية:**
   - زر "إغلاق الفصل وبدء فصل جديد" في لوحة تحكم المدير
   - Dialog مع تحذير وإدخال اسم الفصل الجديد
   - API `/api/terms/active` - جلب الفصل النشط
   - API `/api/terms/close-and-start-new` - إغلاق الفصل وإنشاء فصل جديد
   - API `/api/terms/archive` - عرض الأرشيف
   - أرشفة بيانات الطلاب عند إغلاق الفصل
   - تصفير عدادات الفصل مع الحفاظ على النقاط التراكمية

2. **جدول إحصائيات الطالب:**
   - عرض نقاط الفصل الحالي
   - عدد مرات التسميع
   - عدد ورق المتابعة
   - أيام الحضور والغياب
   - نسبة الحضور

#### ما تم سابقاً في جلسات سابقة:
- نظام التسميع الجديد (RecitationsNew.jsx)
- تصدير PDF لسجل الطالب
- إعدادات مواعيد تسليم ورقة المتابعة

## البنية التقنية

### Backend
- FastAPI + Motor (Async MongoDB)
- JWT Authentication
- Pydantic Models

### Frontend
- React + Tailwind CSS
- Shadcn/UI Components
- Axios للطلبات

### Database Collections
- `users` - المستخدمين
- `groups` - المجموعات
- `tracking_sheets` - ورق المتابعة
- `recitations` - التسميعات
- `attendance` - الحضور
- `terms` - الفصول الدراسية
- `term_archives` - أرشيف الفصول
- `student_points` - نقاط الطلاب
